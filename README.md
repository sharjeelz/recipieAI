# RecipyAI

Turn any YouTube cooking video into a structured recipe you can save, share, and cook from.

Paste a URL → get a clean list of ingredients and step-by-step instructions, generated by an LLM from the video's captions, description, or audio.

## What it does

- **Accepts any YouTube cooking video URL** (standard, shorts, embed, youtu.be).
- **Extracts the recipe** — title, summary, servings, total time, cuisine, ingredients (quantity / unit / item / notes), and numbered steps.
- **Rejects non-recipe videos cheaply** (news clips, product reviews, music-only clips) before running the expensive structuring model.
- **Tracks AI cost per recipe** — you see exactly what each build cost.
- **Saves and shares** — private by default, with a public share link you can send to anyone.

## How it works

```
YouTube URL
     │
     ▼
┌────────────────────────────────────────────────────────────┐
│ 1. Transcript pipeline (tries in order, stops on success)  │
│    a. YouTube captions (free, fast, highest quality)       │
│    b. Video description (free, catches music-only videos)  │
│    c. Whisper transcription (OpenAI API or faster-whisper) │
└────────────────────────────────────────────────────────────┘
     │
     ▼
┌────────────────────────────────────────────────────────────┐
│ 2. Eligibility classifier (~$0.0001/call)                  │
│    Cheap model (Haiku / gpt-4o-mini) decides if the        │
│    transcript is actually a cookable recipe. Rejections    │
│    fail the job with a short reason — no expensive call.   │
└────────────────────────────────────────────────────────────┘
     │  (if recipe)
     ▼
┌────────────────────────────────────────────────────────────┐
│ 3. Structuring LLM                                         │
│    Anthropic (tool-use) or OpenAI (strict JSON schema),    │
│    receives transcript + title + description. Returns a    │
│    normalized recipe.                                      │
└────────────────────────────────────────────────────────────┘
     │
     ▼
    Recipe persisted → frontend polls job → redirects to view
```

The job runs async in an ARQ worker (Redis-backed) so the HTTP request returns immediately. The frontend polls `/jobs/:id` every 1.5s and navigates to the recipe page when it's done.

## Stack

**Backend:** Python 3.11, FastAPI, SQLAlchemy 2.0 (async), Alembic, Postgres, Redis, ARQ, Anthropic + OpenAI SDKs, yt-dlp, youtube-transcript-api, faster-whisper (optional).

**Frontend:** React 19, React Router v6, Vite 6, Tailwind 4.

**Infra:** Docker Compose (postgres + redis + api + worker). Designed to run behind Caddy or nginx on a VPS.

## Getting started

### Prerequisites

- Docker + Docker Compose
- Node 20+ (for the frontend dev server)
- An Anthropic API key **or** an OpenAI API key (or both)

### 1. Backend

```bash
cd backend
cp .env.example .env
cp youtube_cookies.txt.example youtube_cookies.txt
```

The cookies file is a placeholder for dev. In production you replace it with a real export — see `DEPLOY.md` "YouTube cookies file" section.

Edit `.env`:

- `JWT_SECRET` — any long random string
- `LLM_PROVIDER` — `anthropic` or `openai`
- `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` — whichever you chose (plus `OPENAI_API_KEY` if you want Whisper fallback for videos without captions/descriptions)

Bring up the stack:

```bash
docker compose up -d --build
```

Apply migrations (first time only):

```bash
docker compose exec api alembic upgrade head
```

The API is at `http://localhost:8000` — interactive docs at `/docs`, health at `/health`.

### 2. Frontend

```bash
cd recipieaii
cp .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173`. Vite proxies `/api/*` to the backend.

### 3. Use it

1. Register at `/register`.
2. On the home screen, paste a YouTube cooking URL.
3. Watch the job status screen (≈2s for captioned videos, up to a minute if Whisper runs).
4. The recipe opens automatically. Use **Make public** + **Share** to get a shareable link.

## Environment variables (backend)

| Variable                  | Purpose                                                              |
| ------------------------- | -------------------------------------------------------------------- |
| `JWT_SECRET`              | Required. Any long random string.                                    |
| `CORS_ORIGINS`            | Comma-separated origins allowed. Default: `http://localhost:5173`.   |
| `DATABASE_URL`            | Async SQLAlchemy URL. Default points at the compose Postgres.        |
| `REDIS_URL`               | ARQ worker + pool. Default points at the compose Redis.              |
| `LLM_PROVIDER`            | `anthropic` or `openai`. Chooses the structuring model family.       |
| `ANTHROPIC_API_KEY`       | Required if provider is `anthropic`, or if classifier uses Haiku.    |
| `ANTHROPIC_MODEL`         | Structuring model. Default `claude-sonnet-4-6`.                      |
| `OPENAI_API_KEY`          | Required for OpenAI provider and for Whisper API fallback.           |
| `OPENAI_MODEL`            | Default `gpt-4o-mini`.                                               |
| `WHISPER_BACKEND`         | `openai` (API) or `local` (faster-whisper, needs `whisper-local` extras). |
| `ACCESS_TOKEN_TTL_MIN`    | Default 30.                                                          |
| `REFRESH_TOKEN_TTL_DAYS`  | Default 30.                                                          |

## Cost

Typical costs per recipe (as of the prices baked into `backend/app/services/llm/pricing.py`):

| Scenario                                  | Cost           |
| ----------------------------------------- | -------------- |
| Video with captions, classifier accepts   | ~$0.005–0.02   |
| Music-only video, description available   | ~$0.005–0.02   |
| No captions/description, Whisper API runs | ~$0.02–0.05    |
| Non-recipe video (rejected at classifier) | **~$0.0001**   |

Cost is displayed as a pill under the recipe header (`≈ $0.0042`) and tracked on each job row in the database.

## Project layout

```
backend/                 FastAPI + worker
  app/
    main.py              app + CORS + router wiring + lifespan-built job runner
    config.py            pydantic-settings
    db.py                async SQLAlchemy engine/session
    deps.py              typed FastAPI deps
    security.py          bcrypt + JWT
    routers/             auth, recipes, jobs, shares
    models/              SQLAlchemy models (users, recipes, jobs, shares, ...)
    schemas/             Pydantic I/O shapes
    services/
      jobs.py            orchestrates status transitions, InlineJobRunner + ArqJobRunner
      recipe_builder.py  transcript → classifier → structuring → cost
      recipe_store.py    persists a StructuredRecipe into the DB
      transcript/        captions, metadata (title/description), whisper
      llm/               anthropic, openai, pricing, classifier, prompts
    workers/tasks.py     ARQ task entry point
  alembic/               migrations
  tests/                 pytest + httpx; SQLite in-memory
  docker-compose.yml     postgres + redis + api + worker
recipieaii/              Vite + React SPA
  src/
    lib/api.js           fetch wrapper: JWT + single-flight refresh
    lib/auth.jsx         AuthProvider + RequireAuth
    components/          UI primitives, RecipeBody, AppShell
    routes/              Landing, Login, Register, AppHome, JobStatus, RecipeView, Library, Share, NotFound
```

## Running tests

```bash
cd backend
pip install -e ".[dev]"
pytest
```

Tests run against SQLite in-memory and monkeypatch the transcript + LLM layers — no API keys or network required.
